# Complete Project Understanding (Master Reference)

I am working on an R&D project in the field of Continual (Lifelong) Learning. The primary objective of my project is to reduce **Catastrophic Forgetting**, which is one of the biggest challenges in Artificial Intelligence.

Title: Streaming Continual Learning with Adaptive Fisher Memory for Catastrophic Forgetting


## What is Catastrophic Forgetting?

Traditional machine learning models are trained once on a fixed dataset. After training, the model performs well on that dataset but cannot easily learn new information without retraining.

Continual Learning aims to solve this by allowing the model to continuously learn new tasks over time.

However, when a neural network learns a new task, it updates its parameters (weights). These updated parameters often overwrite the knowledge that was learned from previous tasks.

For example:

Task 1:
The model learns to recognize animals.

↓

Task 2:
The model learns to recognize vehicles.

↓

While learning vehicles, the weights responsible for recognizing animals are modified.

↓

The model becomes good at recognizing vehicles but gradually forgets how to recognize animals.

This phenomenon is called **Catastrophic Forgetting**.

Because of this problem, AI systems cannot effectively operate in environments where new data continuously arrives, such as:

- Robotics
- Autonomous Vehicles
- Healthcare Systems
- IoT Devices
- Wearable Devices
- Edge AI
- Surveillance Systems
- Smart Manufacturing

The entire purpose of my research is to reduce this forgetting while allowing the model to continuously learn new information.

# Base Paper

My project is based on the Scientific Reports (Nature Portfolio) paper titled:

"Mitigating Catastrophic Forgetting in Lifelong Learning: A Hybrid Architecture Integrating Neural Ordinary Differential Equations with Memory-Augmented Transformers."

The paper proposes a hybrid continual learning architecture that combines four major components.

1. Neural ODE (Neural Ordinary Differential Equation)

Instead of traditional deep neural network layers,

Input

↓

Layer 1

↓

Layer 2

↓

Layer 3

↓

Output

Neural ODE represents the hidden features as continuous-time dynamics.

Advantages:

• Smooth feature learning
• Stable parameter updates
• Less abrupt weight changes
• Better knowledge preservation

Because the parameters change continuously rather than abruptly, catastrophic forgetting is reduced.

------------------------------------------------------------

2. Memory-Augmented Transformer

Instead of storing all knowledge only inside model weights,

the architecture introduces an external memory.

Whenever a new sample arrives,

the Transformer retrieves useful historical knowledge using its attention mechanism.

Workflow:

Input

↓

Read Memory

↓

Attention

↓

Historical Knowledge

↓

Prediction

Advantages:

• Explicit knowledge storage
• Better reuse of previous information
• Reduced forgetting

------------------------------------------------------------

3. Adaptive Memory Management

The memory cannot store everything forever.

Therefore,

the paper assigns an importance score to every stored sample.

High importance

↓

Keep

Low importance

↓

Lower priority

However,

the paper estimates memory importance using an **Influence Function Approximation**.

Although computationally efficient,

it is still only an approximation and may not always preserve the most valuable memories.

------------------------------------------------------------

4. Adaptive Optimization Strategy

During continual learning,

gradient updates are modified so that learning a new task causes less interference with old tasks.

This balances:

• Plasticity (learning new knowledge)

and

• Stability (preserving old knowledge)

------------------------------------------------------------

# Results Reported in the Base Paper

The paper reports:

• 24% reduction in catastrophic forgetting
• 10.3% improvement in average accuracy

The architecture is evaluated using three public benchmark datasets:

• Split CIFAR-100
• Permuted MNIST
• CORe50

Each dataset is evaluated separately.

The datasets are public benchmark datasets and are not modified by the authors.

# Understanding the Research Gaps

After carefully analyzing the paper, I identified several practical limitations.

------------------------------------------------------------

Gap 1 — Offline Task-Based Learning

The paper assumes data is already divided into predefined tasks.

Example:

Task 1

↓

Task 2

↓

Task 3

↓

Task 4

This works well for research benchmarks.

However,

real-world AI systems do not receive data like this.

Instead,

data continuously arrives.

Example:

Camera

↓

Frame

↓

Frame

↓

Frame

↓

Forever

or

IoT Sensor

↓

Reading

↓

Reading

↓

Reading

↓

Continuous Stream

Therefore,

the current architecture is designed for offline task-based continual learning rather than real-world streaming continual learning.

------------------------------------------------------------

Gap 2 — Approximate Memory Importance

The paper estimates memory importance using Influence Function Approximation.

Although useful,

it is only an approximation.

As the number of learned tasks increases,

important memories may still receive low scores,

causing useful knowledge to be removed.

A more reliable importance estimation method is needed.

------------------------------------------------------------

Gap 3 — Memory Growth

The paper assumes memory continues storing samples as learning progresses.

Real-world devices cannot support unlimited memory.

Examples include:

• Mobile Phones
• Embedded Systems
• IoT Devices
• Smart Watches
• Edge AI Devices

Eventually,

memory becomes full.

Therefore,

a bounded memory management strategy is required.

------------------------------------------------------------

Gap 4 — Lack of Real Streaming Validation

Although CORe50 contains sequential video data,

the evaluation still follows predefined benchmark tasks.

The paper does not validate the model under real online streaming conditions such as:

• Live APIs
• Sensor Streams
• Camera Streams
• Continuous User Data

Therefore,

the practical deployment capability remains unexplored.

------------------------------------------------------------

# My Research Objective

My research does NOT propose an entirely new continual learning architecture.

Instead,

I extend the existing Neural ODE + Memory-Augmented Transformer framework.

The objective is:

"Improve memory management and convert the offline continual learning architecture into a practical streaming continual learning system while further reducing catastrophic forgetting."

------------------------------------------------------------

# Proposed Contribution 1

Streaming Continual Learning

Instead of predefined tasks,

the model continuously receives new real-world data.

Possible sources include:

• APIs
• IoT Sensors
• Cameras
• Wearable Devices
• Mobile Devices
• Live Applications

Workflow:

Real-Time Data

↓

API

↓

Classifier

↓

Streaming Buffer

↓

Continual Learning Model

The classifier organizes incoming data before sending it to the continual learning architecture.

Advantages:

• Continuous learning
• Real-world deployment
• No predefined task boundaries
• Online model updates

------------------------------------------------------------

# Proposed Contribution 2

Fisher-Information-Based Adaptive Memory Management

Instead of Influence Functions,

I propose using Fisher Information.

Fisher Information measures how important each parameter is to the model.

If a parameter has high Fisher Information,

changing that parameter would significantly affect model performance.

Therefore,

memories associated with highly important parameters should receive higher priority.

Workflow:

Stored Memory

↓

Compute Fisher Information

↓

Assign Importance Score

↓

Rank Memories

↓

Preserve Important Memories

Advantages:

• Better importance estimation
• Better preservation of useful knowledge
• Reduced forgetting
• Improved long-term retention

------------------------------------------------------------

# Proposed Contribution 3

Adaptive Fixed-Size Memory Eviction

Instead of allowing memory to grow indefinitely,

the system maintains a fixed memory capacity.

Whenever memory becomes full,

the following process is performed.

Memory Full

↓

Compute Fisher Score

↓

Rank Stored Memories

↓

Remove Lowest Priority Samples

↓

Store New Samples

Advantages:

• Constant memory usage
• Suitable for embedded systems
• Suitable for Edge AI
• Prevents unlimited memory growth
• Efficient long-term learning

------------------------------------------------------------

Workflow:

Streaming Buffer

↓

↓

↓

This creates a complete memory lifecycle where streaming data enters the model, important memories are identified using Fisher Information, low-priority memories are evicted when memory is full, and the updated memory is used for future learning.

# Novelty of the Research

The novelty of this project is NOT creating a completely new continual learning architecture.

Instead, the novelty comes from extending an existing state-of-the-art architecture by introducing three practical improvements:

1. Streaming Continual Learning to replace offline task-based learning with continuous real-world data ingestion.

2. Fisher-Information-Based Adaptive Memory Management to replace approximate influence-function memory scoring with a more principled and reliable importance estimation method.

3. Adaptive Fixed-Size Memory Eviction to maintain bounded memory by retaining high-value memories and evicting low-priority ones.

Together, these three contributions transform the original Neural ODE + Memory-Augmented Transformer framework into a more practical, scalable, deployment-ready, and real-world continual learning system while further mitigating catastrophic forgetting.
